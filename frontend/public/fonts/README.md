# ChessHub fonts

These WOFF2 files are self-hosted so Vietnamese text does not depend on a request to Google Fonts at runtime.

- Be Vietnam Pro: body and controls; weights 400, 500, 600, 700.
- Playfair Display: brand and presentation headings; weights 600, 700.
- Both families include Vietnamese, Latin and Latin Extended subsets, with Unicode ranges in `src/fonts.css`.

Source: Google Fonts CSS API (`fonts.googleapis.com`) and font files (`fonts.gstatic.com`).
License: SIL Open Font License 1.1; see the corresponding `*-OFL.txt` files here.

Typography tokens: `--font-body` and `--font-display` in `src/fonts.css`.
